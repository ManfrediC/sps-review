# Stage-05 autoresearch archive

Retired on `2026-04-13`.

This archive preserves the former stage-05 autoresearch bundle:
- the frozen harness under `src/autoresearch/stage_05/`
- the isolated `_autoresearch` pipeline copies under `src/pipelines/`
- the dedicated `test_stage05_*.py` test files
- the saved watcher logs and non-canonical benchmark runs under `qa/trimming/gold_standard/autoresearch/`

The reviewed gold papers and the shared live `qa/trimming/gold_standard/manifest.json` were intentionally left outside this archive because the manual stage-05 review workflow still uses them.

Nothing under this folder is part of the active pipeline or the default `pytest` collection.
