This archive preserves the deterministic stage-05 review material that previously lived under `qa/trimming/`.

- `batches/`
  - historical deterministic batch manifests `batch_001` to `batch_011`
- `reports/`

- `gold_standard/tranche_reports/`

The active LLM bootstrap tranche outputs remain live under `qa/trimming/gold_standard/tranche_reports/`.
